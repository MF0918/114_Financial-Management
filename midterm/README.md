| **1.1** | 財務管理決策的類型 | 財務管理決策包括三種類型：**資本預算 (Capital Budgeting)**，即決定推行哪些長期投資計畫；**資本結構 (Capital Structure)**，即決定如何取得資金（籌資方式）；以及**營運資金管理 (Working Capital Management)**，即決定發放多少股利（或股票回購）。 | |

| **1.4** | 財務組織與財務長職責 | 財務長 (CFO) 是公司內最高的財經主管。課程內容主要集中在公司理財的理論與觀念，但未明確列出財務長所掌管的兩個單位名稱及其具體職責劃分。 | |
| **1.5** | 財務管理的目標 | 企業財務經理應該追求的目標是**股東財富最大化** (Value Maximization)，具體來說，即是**公司股票當前的價值最大化**，或使**股東權益的市場價值最大化**。 | |
| **1.6** | 代理問題 | 公司由**股東 (Shareholders)** 擁有。股東透過**董事會 (Board of Directors)** 對經理人提出要求以進行控制。代理關係存在的主因是**所有權人與管理階層之間可能引發的利益衝突**。問題可能導致管理階層追求與股東利益不符的目標。 | |
| **1.7** | 初級與次級市場 | 首次公開發行（IPO）屬於**初級市場 (Primary Market)** 交易。 | |
| **1.10** | 倫理與企業目標 | 理論上，使股票價值最大化這個目標應與避免不道德或不合法行為的目標**不衝突**。企業應將環境、社會公益（ESG）等納入考量。價值最大化是建立在不違法的基礎上。 | |
| **1.11** | 國際企業目標 | 來源中未直接討論在國際財務管理中，股票價值最大化目標是否仍適用。 | - |
| **1.12** | 代理問題 (敵意收購) | 在股價 $25 而收購價 $35 的情況下，管理階層若抵抗這起收購，可能**不符合**股東的最佳利益，因為經理人可能是在保護自己的職位，而非實現股東的財富增值（經典的代理問題）。 | |
| **1.15** | 沙賓法案 (SOX) | 來源中未提供小型公司寧可「下市」以回應沙賓法案的具體原因和相關成本。 | - |

### Chapter 2 關鍵思考與概念回顧

| 題號 | 問題核心 | 簡短重點解答 | 來源 |
| :--- | :--- | :--- | :--- |
| **2.2** | 會計淨利與現金流量的差異 | 損益表數據可能不代表實際現金流出入，因為會計採用**權責發生制**，收益和成本在發生時記錄，不一定與實際現金交換同步。例如，折舊 (Depreciation) 是一種非現金支出。 | |
| **2.3** | 帳面價值著重歷史成本 | 標準會計實務會著重歷史成本而非市場價值，主因是會計原則強調**保守性 (Conservatism)**，避免預估市場波動與未來前景。 | |
| **2.4** | 淨利與營運現金流量的差異項目 | 兩個項目出現在淨利中，但不在營運現金流量（OCF）中的是：**利息費用 (Interest Expense)** 和 **折舊費用 (Depreciation Expense)**。利息費用被排除在 OCF 之外，因為它是屬於籌資活動中付給債權人的現金流。折舊費用則因為是**非現金支出**而被排除。 | |
| **2.5** | 負債超過資產 (負的股東權益) | 根據標準會計法則（帳面價值觀點），公司的負債**可能**超過其資產，導致業主權益為負。但從市場價值觀點來看，這種情況**不可能**發生，因為市場價值反映了公司的未來前景。 | |
| **2.7** | 負營運現金流量的解讀 | 來源中沒有明確界定連續幾年負 OCF 是好是壞，但現金流量對於企業生存至關重要。 | |
| **2.8** | 淨營運資本與淨資本支出 | 淨營運資本（NWC）可以為負。淨資本支出通常是正的，反映了新增的廠房設備或長期資產投資。 | |
| **2.10** | 帳面價值削減與股東損失 | 報表上記載的損失（帳面價值削減）是基於歷史成本和會計原則。股東更關注的是**市場價值**；如果公司的市場價值（反映未來前景）沒有受到影響，股東可能並未實際蒙受損失。 | |

### Chapter 2 問題 (計算題/分析題)

| 題號 | 問題核心 | 簡短重點解答 | 來源 |
| :--- | :--- | :--- | :--- |
| **1-12, 13-14, 18-23** | 計算題（製作報表、計算淨利、OCF、股東現金流量等） | 這些問題要求運用損益表和資產負債表的數據進行計算，計算仰賴以下核心公式：<br>1. **資產負債表恆等式：** 資產 = 負債 + 股東權益。<br>2. **淨營運資本 (NWC)：** 流動資產 - 流動負債。<br>3. **淨利 (Net Income)：** (銷貨收入 - 銷貨成本 - 折舊 - 利息費用) × (1 - 稅率)。<br>4. **營運現金流量 (OCF)：** EBIT + 折舊 - 稅。<br>5. **股東現金流量：** 股利支出 - 淨新增權益。<br>6. **總現金流量恆等式：** 資產的現金流量 = 債權人現金流量 + 股東現金流量。 | |
| **18** | 邊際與平均稅率 | **平均稅率**是總稅額佔應稅所得的比例。**邊際稅率**是在下一筆 $10,000 應稅所得上支付的稅率。如果兩家公司落在相同的稅率區間，新增的稅額（即邊際稅額）會是一樣的。 | |
| **21c** | 營運現金流量的正負號意義 | 營運現金流量為負，通常是壞跡象，表示營運無法產生足夠現金。 | |

### Chapter 3 運用財務報表

| 題號 | 問題核心 | 簡短重點解答 | 來源 |
| :--- | :--- | :--- | :--- |
| **3.4** | 財務比率提供的訊息類型 | 財務比率可分為五大類，提供不同類型的訊息：<br>a. **速動比率**：衡量短期流動性/償債能力。<br>e. **權益乘數 (EM)**：衡量槓桿程度/負債規模。<br>f. **利息保障倍數 (TIE)**：衡量長期生存所需/償債能力 (能否支付利息)。<br>h. **資產報酬率 (ROA)**：衡量資產的獲利效能。<br>i. **權益報酬率 (ROE)**：衡量股東權益的獲利效能。<br>j. **本益比 (P/E)**：衡量市場價值相對於淨利的評價。 | |
| **3.5** | 標準化財務報表的功能 | 共同比報表（Common Size）將所有項目轉換為百分比，用於比較**不同規模的公司**，尤其適用於相同產業，或用於比較**同一公司不同時間**的趨勢變化。 | |
| **3.7** | 杜邦恆等式的價值 | 杜邦恆等式 (DuPont Identity) 將 ROE 拆解為：邊際獲利 $\times$ 總資產週轉率 $\times$ 權益乘數。它有價值，因為它揭示了**公司績效（ROE）的驅動因素**，讓分析師能夠診斷績效是來自高獲利能力、高資產運用效率，還是高槓桿程度。 | |
| **9** | 平均應付帳款付款期間 (長短意涵) | 來源中雖然未直接解釋數值很大的意涵，但其計算屬於資產管理效能比率。若平均付款天數過長，可能暗示公司對供應商存在議價能力，但也可能暗示其短期流動性壓力。 | |
| **45** | 內部與可支撐成長率 (IGR/SGR) | **內部成長率 (IGR)** 是指公司僅使用**保留盈餘**（不增加負債）作為唯一資金來源時，能夠達到的最大成長率。<br>**可支撐成長率 (SGR)** 是指公司在維持**現有槓桿比率不變** (同步增長負債) 的情況下，能夠達到的最大成長率。SGR 公式為 $SGR = (ROE \times b) / (1 - ROE \times b)$，其中 $b$ 為盈餘保留率。 | |

### Chapter 5 折現現金流量評價

| 題號 | 問題核心 | 簡短重點解答 | 來源 |
| :--- | :--- | :--- | :--- |
| **5.1** | 年金期數對 PV/FV 的影響 | 期數增加，年金的現值 (PV) 和終值 (FV) 都會**增加**。 | |
| **5.2** | 利率對年金 PV/FV 的影響 | 利率增加，年金終值 (FV) 會**增加**；年金現值 (PV) 會**下降**。 | |

| **5.5** | 合約談判（球員 vs. 球隊） | 球員希望立即拿一大筆紅利金，以實現立即效用和降低風險。球隊則傾向於延期支付（年金型付款），以降低合約的現值成本。 | |

### Chapter 6 利率與債券評價

| 題號 | 問題核心 | 簡短重點解答 | 來源 |
| :--- | :--- | :--- | :--- |
| **6.1** | 政府公債的風險 | 美國政府發行的證券（公債）**並非完全無風險**。雖然它被認為沒有**違約風險 (Default Risk)**，但仍存在**利率風險 (Interest Rate Risk)**、**再投資風險 (Reinvestment Risk)** 和**通貨膨脹風險 (Inflation Risk)**。 | |
| **6.2** | 利率風險比較 | 利率風險主要取決於**到期期間 (Maturity)** 和**票面利率 (Coupon Rate)**。在到期日相同的情況下，理論上票面利率越低，利率風險越大。BB級的公司債雖然總體風險（含違約）較高，但利率風險需依票面利率等因素判斷。 | |
| **6.5** | 贖回條款的成本與好處 | 對公司而言，納入**贖回條款**的好處是，若市場利率下降，公司可贖回債券並進行**再融資 (refinance)**，降低資金成本。成本是投資人要求更高的必要報酬率 (YTM)。<br>**賣回條款**（Put Provision）的效果則相反，對投資人有利，對公司不利。 | |
| **6.6** | 票面利率的決定 | 債券發行人通常會將票面利率設定為**市場對該債券要求的必要報酬率 (YTM)**，以便以面值出售債券。票面利率是固定不變的；必要報酬率（YTM）是市場根據風險動態要求的利率。 | |
| **6.7** | 實質與名目報酬率 | **名目報酬率**是指未經通膨調整的報酬率，它會隨通膨（或通縮）而變化。投資人在某些情境下會更關心名目報酬率（例如，當通膨被鎖定時）。 | |
| **6.8 & 6.13** | 債券評等機構 | 公司願意支付龐大費用進行債券評等，因為評等能夠**降低投資人的資訊不對稱**，使債券更容易被投資人接受，且能以較低的必要報酬率發行。若評等機構主動提供評等，爭議點在於其**獨立性和客觀性**可能受到質疑。 | |
| **6.15a** | 債券價格與 YTM 的關係 | 債券價格與其到期殖利率 (YTM) 之間存在**反向關係**。 | |
| **6.15b** | 溢價/折價/面值債券的票面利率與 YTM 關係 | **溢價**：票面利率 > YTM。<br>**折價**：票面利率 < YTM。<br>**面值**：票面利率 = YTM。 | |
| **6.15c** | 溢價/折價/面值債券的目前殖利率與 YTM 關係 | **溢價**：目前殖利率 > YTM。<br>**折價**：目前殖利率 < YTM。<br>**面值**：目前殖利率 = YTM。 | |

### Chapter 7 股權市場評價

| 題號 | 問題核心 | 簡短重點解答 | 來源 |
| :--- | :--- | :--- | :--- |
| **7.1** | 股票價值依據股利而定 | 股票價值依據股利而定，因為股票能夠為投資人提供現金流的主要來源是**股利**。在股利折現模型 (DDM) 中，股票的現值是**所有預期未來股利現值的總和**。未來賣出的股價 (P$_t$) 本身也是由之後的股利折現而來，因此股利是價值評估的基礎。 | |
| **7.2** | 不發放股利的股票 | 投資者願意購買不發放股利的股票，是因為預期公司未來會開始發放股利，或未來股利會大幅成長。 | |
| **7.5** | 普通股對特別股 | **普通股 (Common Stock)** 價格通常會比特別股高。因為特別股通常被視為零成長的永續年金，而普通股的價值通常包含了**預期股利成長率 (G)**。 | |
| **7.6** | 股利成長模式下的總報酬率組成 | 股利成長模式 (DDM) 下，股票總報酬率 (R) 由兩部分組成：**股利收益率 (Dividend Yield)** 和 **資本利得收益率 (Capital Gains Yield)** (即股利成長率 G)。 | |
| **7.7** | 股利成長率與股價成長率 | 根據固定成長模式（高登模式/GGM），股利成長率 (G) 真的與股價成長率**完全相同**。 | |
| **7.8** | 虧損與支付股利 | 雖然公司本年度虧損，仍**有可能**支付股利，通常是動用保留盈餘支付。但長期來看，公司不可能持續虧損並支付股利。 | |
| **7.11** | 管理者對目前股價的關注 | 管理者不應完全忽略目前的股價，因為目前的股價反映了市場對公司**長期利益**的預期和評價。如果管理者過度強調短期利益，長期來看仍可能傷害股價。 | |
