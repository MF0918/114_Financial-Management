### 核心財務公式對照表

#### I. 財務報表基本恆等式與定義 (Chapter 2)

| 類別 | 公式名稱 | 核心公式 | 來源 |
| :--- | :--- | :--- | :--- |
| **資產負債表** | 資產負債表恆等式 (Balance Sheet Equation) | **資產 ＝ 負債 ＋ 股東權益** | |
| **資產負債表** | 股東權益 (Shareholders' Equity) | **股東權益 ＝ 資產 － 負債** | |
| **營運資本** | 淨營運資本 (Net Working Capital, NWC) | **NWC ＝ 流動資產 － 流動負債** | |
| **損益表** | 淨利 (Net Income, NI) | **淨利 ＝ 收益 － 費用** | |
| **稅賦** | 平均稅率 (Average Tax Rate) | **平均稅率 ＝ 稅額 ／ 應稅所得** | |

#### II. 現金流量計算 (Chapter 2)

| 類別 | 公式名稱 | 核心公式 | 來源 |
| :--- | :--- | :--- | :--- |
| **資產現金流量** | 資產的現金流量 (CFFA, Cash Flow From Assets) (亦稱自由現金流量 FCF) | **CFFA ＝ 營運現金流量 (OCF) － 淨資本支出 (NCS) － 淨營運資本的改變 ($\Delta$NWC)** | |
| **營運現金流量** | OCF (Operating Cash Flow) | **OCF ＝ 稅前息前盈餘 (EBIT) ＋ 折舊 － 稅** | |
| **資本支出** | 淨資本支出 (Net Capital Spending, NCS) | **NCS ＝ (期末淨固定資產 － 期初淨固定資產) ＋ 折舊** | |
| **股東/債權人** | CFFA 恆等式 (分配角度) | **CFFA ＝ 付給債權人的現金流量 (CF/CR) ＋ 付給股東的現金流量 (CF/SH)** | |
| **債權人現金流量**| CF/CR (Cash Flow to Creditors) | **CF/CR ＝ 利息支出 － 新借款淨額** | |
| **股東現金流量** | CF/SH (Cash Flow to Stockholders) | **CF/SH ＝ 股利支出 － 新增權益淨額** | |

| 類別 | 分類 | 公式名稱 | 核心公式 | 來源 |
| :--- | :--- | :--- | :--- | :--- |
| **流動性比率** | 短期償債能力 | 流動比率 (Current Ratio) | **流動資產 ／ 流動負債** | |
| | | 速動比率 (Quick Ratio) | **(流動資產 － 存貨) ／ 流動負債** | |
| **財務槓桿比率** | 長期償債能力 | 總負債比率 (Total Debt Ratio) | **(總資產 － 總權益) ／ 總資產** | |
| | | 負債權益比 (Debt-to-Equity Ratio) | **總負債 ／ 總權益** | |
| | | 權益乘數 (Equity Multiplier, EM) | **總資產 ／ 總權益** (等於 $1 + \text{負債權益比}$) | |
| | | 利息保障倍數 (TIE) | **EBIT ／ 利息** | |
| **資產管理比率** | 營運效能 | 存貨週轉率 (Inventory Turnover) | **銷貨成本 ／ 存貨** | |
| | | 應收帳款週轉率 (Receivables Turnover) | **銷貨金額 ／ 應收帳款** | |
| | | 總資產週轉率 (Total Asset Turnover, TAT) | **銷貨收入 ／ 總資產** | |
| | | 存貨銷售期間 (Days Sales in Inventory) | **365 ／ 存貨週轉率** | |
| **獲利比率** | | 邊際獲利 (Profit Margin, PM) | **淨利 ／ 銷貨收入** | |
| | | 資產報酬率 (Return on Assets, ROA) | **淨利 ／ 總資產** | |
| | | 權益報酬率 (Return on Equity, ROE) | **淨利 ／ 總權益** | |
| **市場價值比率** | | 每股盈餘 (EPS) | **淨利 ／ 流通在外股數** | |
| | | 本益比 (P/E Ratio) | **每股價格 (PPS) ／ EPS** | |
| | | 市價對帳面價值比率 (M/B Ratio) | **PPS ／ 每股帳面價值 (BVPS)** | |

#### IV. 杜邦恆等式與成長模型 (Chapter 3)

| 類別 | 公式名稱 | 核心公式 | 備註 | 來源 |
| :--- | :--- | :--- | :--- | :--- |
| **杜邦恆等式** | ROE (第二階段) | $\text{ROE} = \text{PM} \times \text{TAT} \times \text{EM}$ | PM: 邊際獲利；TAT: 總資產週轉率；EM: 權益乘數 | |
| **杜邦恆等式** | ROA (第一階段) | $\text{ROA} = \text{PM} \times \text{TAT}$ | 衡量資產運用與營運效率 | |
| **保留比率** | 盈餘保留率 (b) | **$b = 1 - \text{股利發放率}$** | 保留盈餘／淨利 | |
| **成長模型** | 內部成長率 (IGR) | $IGR = \frac{\text{ROA} \times b}{1 - (\text{ROA} \times b)}$ | 僅使用保留盈餘作為融資資金來源時的成長率 | |
| **成長模型** | 可支撐成長率 (SGR, $g$) | $SGR = \frac{\text{ROE} \times b}{1 - (\text{ROE} \times b)}$ | 維持負債比固定的條件下，同時發行新債取得資金時的成長率 |
| **SGR 簡化** | 可支撐成長率 (簡化版) | $\mathbf{SGR} \approx \text{ROE} \times b$ | 多數財管課本常用此簡化版本進行概念理解 |

#### V. 貨幣時間價值與年金 (TVM & Annuities) (Chapter 4 & 5)

| 類別 | 公式名稱 | 核心公式 | 來源 |
| :--- | :--- | :--- | :--- |
| **單筆流量** | 終值 (Future Value, FV) | $\text{FV} = \text{PV} \times (1 + r)^t$ | |
| **單筆流量** | 現值 (Present Value, PV) | $\text{PV} = \frac{\text{FV}}{(1 + r)^t}$ | |
| **單筆流量** | 利率 (r) | $r = (\text{FV} / \text{PV})^{1/t} - 1$ | |
| **永續年金** | 永續年金現值 (Perpetuity PV) | $\mathbf{PV = \frac{C}{r}}$ | C 為固定現金流 (Payment)；期數無限 |
| **普通年金** | 年金現值 (Ordinary Annuity PV) | $PV = C \times \left[ \frac{1 - 1 / (1+r)^t}{r} \right]$ | C 為固定現金流；期數有限 |
| **普通年金** | 年金終值 (Ordinary Annuity FV) | $FV = C \times \left[ \frac{(1+r)^t - 1}{r} \right]$ | |
| **期初年金** | 期初年金與普通年金的關係 (Annuity Due) | $\text{期初年金 PV} = \text{普通年金 PV} \times (1 + r)$ | 期初年金的現金流量發生在每期期初 |
| **複利期間** | 有效年利率 (Effective Annual Rate, EAR) | $EAR = \left[ 1 + \frac{\text{APR}}{m} \right]^m - 1$ | APR 為年公佈利率，m 為每年複利次數 |

#### VI. 資產評價 (Valuation) (Chapter 6 & 7)

| 類別 | 公式名稱 | 核心公式 | 備註 | 來源 |
| :--- | :--- | :--- | :--- | :--- |
| **債券評價** | 債券價格 (Bond Price) | $\text{債券價格} = \text{票息的現值} (\text{年金 PV}) + \text{面值的現值} (\text{單筆 PV})$ | | |
| | 到期殖利率近似值 (YTM Approximation) | $\text{YTM} \approx \frac{C + (FV - P) / t}{(FV + P) / 2}$ | 僅為近似值，用於無法使用財務計算機時 |
| | 目前殖利率 (Current Yield) | $\text{目前殖利率} = \frac{\text{每年票息}}{\text{債券價格}}$ | | |
| **股票評價** | 股利折現模型 (DDM) | $\mathbf{P_0 = \sum_{t=1}^{\infty} \frac{D_t}{(1+R)^t}}$ | 股票價格是所有預期未來股利的現值總和 | |
| **股票評價** | 零成長股利 (Zero Growth) | $P_0 = \frac{D}{R}$ | D 為固定股利 (如同特別股) |
| **股票評價** | 固**定成長股利 (高登模型)** (Gordon Model) | $\mathbf{P_0 = \frac{D_1}{R - g}}$ | $D_1$: 一年後股利；$R$: 必要報酬率；$g$: 股利成長率 |
| **股票報酬率** | 必要報酬率 (Required Return) | $R = \frac{D_1}{P_0} + g$ | R ＝ 股利收益率 ＋ 資本利得收益率 | |
